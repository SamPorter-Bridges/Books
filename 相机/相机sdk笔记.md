

# 相机sdk笔记

## 句柄层次结构

### interface-通讯方式的接口

他解决的问题是: 我选择相机的通讯方式是什么？

### device-设备种类的接口

他解决的问题是:我要启动哪几个相机去采集

设备（Device）分为本地设备（Local Device）和远程设备（Remote Device），本地设备是远程设备的一个代理，本地设备的责任是启用与远程设备的通信，以及枚举和实例化数据流（Data Stream）。

### dataStream-数据流接口

设备采集图片之后,是可以选择不同的数据流里放入图片的。这么做是为了不同拍照任务隔离使用。

### buffer-图片缓存容器

缓存区可以缓存多次拍照的图片

## 根据结构得出使用sdk的逻辑

```python
if 通讯接口初始化ok:
  获取通讯接口句柄;
  根据通讯接口导入设备句柄；
  开启期望数据流接口；
  触发设备的拍照后采集图片；
```
